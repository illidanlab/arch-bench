# Changelog

All notable changes to the ARCH-Bench corpus are recorded here. Releases are
immutable: a published version is never edited in place, and corrections arrive
as a new version.

## v1.0.0-alpha.2 — 2026-09-14

Initial public data release.

- 36 synthetic child–parent dyad cases (`ABV0-R1-0001` … `ABV0-R1-0036`) under
  `corpus/v1.0.0-alpha.2/`, with a release manifest recording a SHA-256 for
  every case body and for every documentation artifact in the repository.
- Case schema `0.5.0` (`schemas/v0.5/`), ontology `0.2.0` (`ontology/`), and the
  annotation guide the labels were proposed under (`docs/`).
- Data card (`docs/DATA_CARD.md`) and known issues
  (`corpus/v1.0.0-alpha.2/known_issues.md`).

Annotations in this release are machine-generated and pending expert
verification; a verified release will follow.
